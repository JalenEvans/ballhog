# ballhog

`ballhog` is the home of sport-statistics .NET SDK packages. Each sport ships as
its own NuGet package in its own top-level directory.

## Packages

- **`BallhogBasketball`** — typed async .NET client for NBA statistics. Package
  source and documentation: [`Ballhog.Basketball/README.md`](Ballhog.Basketball/README.md).

Future sport packages will follow the same pattern: one package per sport, each
in its own top-level directory with its own README.
